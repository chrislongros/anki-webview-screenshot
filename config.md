### Web View Screenshot

- `directory`: folder for the PNG and PDF files. `~` expands to your home folder.
- `save_to_file`: write a PNG there (`true`/`false`).
- `copy_to_clipboard`: put the PNG on the clipboard (`true`/`false`).
- `shortcut_pick`: start the element/region picker. Default `Ctrl+Shift+S` (Cmd on macOS).
- `shortcut_fullpage_pdf`: save the whole page as a PDF. Default `Ctrl+Shift+D`.

Restart Anki after changing the shortcuts.
